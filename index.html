Xuất Bản & Đóng Gói Tác Phẩm

Tự động chèn ảnh bìa chuẩn, định dạng trang sách, chia ngắt chương (Page Break) và xuất ra file Word hoặc eBook mở trên Apple Books / Kindle.

Tải Toàn Bộ Sách (.DOCX)

Tạo file Microsoft Word chuẩn với thư viện docx.js: Trang đầu tiên hiển thị trang trọng ảnh bìa tác phẩm, tên sách và tác giả; tự động ngắt trang (Page Break) chuẩn mực giữa các chương.

  • Nhúng ảnh bìa gốc Base64 vào Trang 1
  • Chèn Page Break trước mỗi chương mới
  • Font chuẩn Literata / Times New Roman, dãn dòng 1.5

Tải Toàn Bộ Sách (.EPUB)

Tự động đóng gói cấu trúc EPUB v3.0 tiêu chuẩn bằng JSZip + FileSaver.js: Bao gồm mimetype, META-INF/container.xml, content.opf, mục lục toc.ncx, trang bìa cover.xhtml và từng chương chapter-N.xhtml.

  • Tương thích 100% Apple Books, Kindle, Moon+ Reader, Kobo
  • Tích hợp mục lục TOC nhảy nhanh từng chương
  • Nhúng metadata tác giả, ngày xuất bản và bìa sách

Kho Lưu Trữ Thành Phẩm Trên Cloud

Khi bạn tải file .EPUB hoặc .DOCX, sách được tự động đẩy lên Cloud và lưu Public URL vĩnh viễn.

Lưu Trữ Cloud Sẵn Sàng
Định dạng đường dẫn: cloud_storage/{userId}/{bookId}/tên_sách.ext

Chưa có liên kết tải từ Cloud cho dự án này. Hãy bấm xuất file ở trên để lưu vào kho.

Sao Lưu & Phục Hồi Dữ Liệu Cục Bộ (IndexedDB)

Toàn bộ dữ liệu tác phẩm và key được lưu trữ an toàn trong IndexedDB của trình duyệt. Bạn có thể sao lưu ra file JSON để đồng bộ sang thiết bị khác.
